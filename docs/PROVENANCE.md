# 来源与贡献

本项目源自 QGroundControl：https://github.com/mavlink/qgroundcontrol 。

初始公开快照基于 HDZX Android 2.0.27 的公开精简整理；开发工程所记录的 QGroundControl 基础提交为 `f1883f93a5ba0b5e9c1ec88b3815b290e2608697`。公开仓库从清理后的源码快照建立历史，不包含内部开发记录；这不改变上游作者、版权或许可证。

HDZX 的改动包含中文移动界面、侧栏及工具箱、经典 HUD、参数与 PID 显示、中文解释及录音播报、外设配置建议、地图显示改进等。详情以源码和版本记录为准，不宣称独立从零实现 QGroundControl 或第三方组件。

上游双许可文字和第三方许可文件予以保留；组合发行选择 GPLv3。Qt 和第三方组件还须遵守各自的许可要求。

语音资源为维护者确认可使用的合成音色所生成的提示录音；仓库不包含参考音频、生成模型或外部服务凭据。Qt、地图、图传等依赖及素材的原始许可见项目文件头与 resources/licenses。在线地图和外部 AI 服务的使用还受各服务条款约束。
