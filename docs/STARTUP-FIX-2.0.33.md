# 开源发布版 2.0.33 · 2026-11-04

TB711FU 平板上的 2.0.28 启动时，QML 引擎报告 `HQFlightGeoScene is not a type`，继而主窗口加载失败并以状态 0 退出。两个飞行地图组件原先只列在 `target_sources`，没有加入模块的 `QML_FILES`。本次修正组件注册，并在源码检查中加入相应规则。

本修复延续本地 2.0.29 的虚拟摇杆修改，保留开源发布版既有功能边界。没有重新加入已移除的集群等功能。

实机验证：同一 TB711FU 平板成功覆盖安装 2.0.33，保留应用数据；主窗口通过加载，30 秒启动观察结束后没有新的进程退出记录。之后 USB 调试连接断开，尚未完成页面切换、长时间运行或飞控连接测试。
