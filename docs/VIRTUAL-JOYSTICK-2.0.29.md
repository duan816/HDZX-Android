# 2.0.29 虚拟摇杆修订

- 普通浮动仪表不再挡住摇杆；独立计算左右边距，局部坐标拖动，恢复触摸取消／隐藏／失焦后的输入。
- 应用设置 → 飞行视图 → 虚拟摇杆 → 虚拟摇杆大小：50%～150%，默认 100%。
- 触碰摇杆时保持原输出、拖动才改变数值；保留油门不回中和缩放后的油门值。
- 确认飞控解锁／锁定后，用打包的固定男声提示；解锁请求遭拒或超时失败后提示查看报错。
- 返航点为对齐 Home 坐标的黄色圆圈 H。

Qt 输入测试 16 项、120 轮中断恢复、音频单元测试 41 项通过。当前没有连接安卓调试设备或飞控，未做实机／飞行验证。先在地面复测原先会偶发失效的操作过程。
